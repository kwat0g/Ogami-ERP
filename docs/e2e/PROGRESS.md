## Run discipline

Use `node scripts/e2e/runner.mjs reset` for a known baseline, then run a single journey at a time through headless Chromium with one worker. Never start the PHP full test suite alongside browser work. Read-only API/DB assertions are allowed; transactional records must be created, advanced, approved, and cancelled through the UI by the owning role's own session. No `waitForTimeout` sleeps and no retries to erase failures.

For the recurring short-window service interruption, use `E2E_AUTH_ACTORS=<comma-separated-actors> node scripts/e2e/runner.mjs test-split --grep <exact-journey-id>`. This guarded command seeds a fresh baseline, signs the selected actors in through the UI, restarts the dedicated services while preserving database and storage volumes, then runs only that journey. ENV-E2E-002 remains open because the stop-signal source is unknown.
